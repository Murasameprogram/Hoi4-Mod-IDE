# 千月堂 MOD IDE - 公告

欢迎使用 **千月堂 MOD IDE**！这是您的 Paradox 游戏 MOD 开发利器。

---

## 🎉 最新版本：v1.0.0 (测试版)

### 新增功能

- ✅ **插件隔离机制**：采用 ALC + MEF2 实现插件间完全隔离
- ✅ **项目管理器重构**：完全参照 Visual Studio 启动页风格

### 修复问题

- 🐛 修复了启动窗口标题栏显示异常的问题
- 🐛 修复了 TreeView 项目列表无法展开/收起的问题
- 🐛 修复了新闻公告区无法正确渲染 Markdown 的问题
